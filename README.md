# dengue-dom-rep

Code and results for "Disentangling spatiotemporal drivers of dengue outbreak dynamics in the Dominican Republic: a semi-mechanistic modelling study". 
This analysis investigates drivers of dengue transmission in the Dominican Republic using a semi-mechanistic Bayesian modelling framework. This includes:

- Estimating the force of infection (FOI) using [RSero](https://journals.plos.org/ploscompbiol/article?id=10.1371/journal.pcbi.1012777) 
- Quantification of climate drivers at the municipality level from 2013-2023 using [R-INLA](https://www.r-inla.org/) 
- Evaluation of model performance via time-series and spatial k-fold cross-validation. 

To reproduce the analysis, open the .Rproj file. The main workflow scripts are:
- code/01_estimate-foi.R
- code/02_run-climate-models.R
- code/03_run-tscv-evaluation.R
- code/04_run-kfold-evaluation.R

Supporting function scripts can be found in:
- code/00_load-packages.R
- code/utils_fn.R
- code/inla-loop_fn.R
- code/evaluate-tscv_fn.R
- code/evaluate-kfold_fn.R
- code/create-lagged-data_fn.R
- code/helper-rsero_fn.R

While plotting scripts can be found in: 
- code/05_plot-data.R
- code/06_plot-catalytic.R
- code/07_plot-model-output.R
- code/08_plot-evaluation-output.R

Model outputs are stored in the `output` folder and figures are generated by the plotting scripts (05-08) into a `figures` folder.

Note that serosurvey data used to estimate force of infection (code/01_estimate-foi.R) is not included in this repository.

Model inputs:
- Demographic data for the Dominican Republic (province and municipality population) from the Oficina Nacional de Estadística (ONE)
- Epidemiological data (weekly reported dengue cases by province and municipality) from the Dominican Republic Ministry of Health's Dirección General de Epidemiología (DIGEPI)
- Climate data: temperature, relative humidity and precipitation (SPI) from ERA5, and Niño 3.4 sea surface temperature anomalies from NOAA
- Shape files for provinces and municipalities in the Dominican Republic from GADM

Technical specifications:
Required packages to reproduce this analysis are listed in `00_load-packages.R`. Note that the time-series and spatial k-fold cross-validation steps (code/03 and code/04) are computationally intensive and designed to be run on an HPC. The scripts are run per model variant via command-line arguments (formula, model name, and for k-fold, number of repetitions and folds).
